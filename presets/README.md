# ChatLuna 预设

- `general.example.yml`：通用研究助理。安装脚本会把它复制到
  `koishi/data/chathub/presets/general.yml`。
- `malfoy.example.yml`：性转德拉科·马尔福同人设定示例（成年人向、偏感官描写）。
  如需启用：

  ```bash
  cp presets/malfoy.example.yml koishi/data/chathub/presets/malfoy.yml
  ```

  然后在 ChatLuna 的预设中选择 `malfoy`。

人设图片不提交到公开仓库；请使用你有权分发的素材，并遵守 ChatLuna/角色原作的
相关许可。
