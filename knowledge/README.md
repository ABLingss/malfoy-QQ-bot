# 研究知识库

运行时生成的论文笔记、研究项目、候选问题、复现笔记和日报副本放在这里。
这些内容通常包含个人研究记录，默认不提交到公开仓库。

初始化后会生成：

- `papers/`：论文 Markdown，自动分析区和人工笔记区分离
- `research-projects/`：研究项目索引
- `literature-reviews/`：文献综述
- `research-questions/`：候选研究问题
- `reproduction-notes/`：复现记录
- `daily-digests/`：日报副本

如果要公开示例，请先删除个人信息、未发表研究内容和受版权限制的全文材料。
